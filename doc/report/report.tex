\section{Naive solution} \label{sec: naive_solution}
Let $M$ and $N$ be the dimensions of the board and $T = M \times N$ the total number of moves.
For every cell $(i,j)$, ($0 \leq i < M$, $0 \leq j < N$) and every time step $t$ ($0 \leq t < T$)
we introduce a Boolean variable $x_{i,j,t}$ representing whether the knight occupies position $(i, j)$ at timestep $t$.

The first attempt at solving the problem involves the following set of constraints.

\paragraph{Timesteps constraints} 
A cell can only be occupied at one timestep. This means we need to ensure both  ``at least one'' and ``at most one'' timesteps. Indeed, cell $(i,j)$ must be visited at time 0, OR time 1, ..., OR time $T-1$. Moreover, there must be at least one time step when the knight visits a cell, and visiting a cell at a previous time step $t_1$ enforces to not revisit it at time step $t_2 > t_1$, guaranteeing each cell is visited exactly once. Formally,

\begin{equation}
    \forall i \in [0, M-1], \forall j \in [0, N-1] : \quad \bigvee_{t=0}^{T-1} x_{i,j,t} = x_{i,j,0} \vee x_{i,j,1} \vee \dots \vee x_{i,j,T-1}
\end{equation}
\begin{equation}
    \forall i, j, \forall t_1 < t_2 : \quad (x_{i,j,t_1} \implies \neg x_{i,j,t_2}) \equiv (\neg x_{i,j,t_1} \vee \neg x_{i,j,t_2})
\end{equation}

\paragraph{Cells constraints}
Similarly to the timestep constraints, these rules enforce that the knight occupies exactly one cell at any given timestep $t$. First, we require the knight to occupy at least one cell on the board. Second, we prohibit it from occupying more than one cell simultaneously. Formally,

\begin{equation}
    \forall t \in [0, T-1] : \quad \bigvee_{i=0}^{M-1} \bigvee_{j=0}^{N-1} x_{i,j,t}
\end{equation}
\begin{equation}
    \forall t \in [0, T-1], \; \forall (i_1, j_1) \neq (i_2, j_2) : \quad \neg x_{i_1,j_1,t} \vee \neg x_{i_2,j_2,t}
\end{equation}

\paragraph{Legal moves} 
The rules of chess constrain the knight's transitions between timesteps. From a cell $(i, j)$ at timestep $t$, a knight moves in an ``L-shape'' to one of up to eight valid board positions at timestep $t+1$. We thus enforce the knight reaches one of these destinations. Let $L(i, j)$ denote the set of legal destination cells reachable from $(i, j)$~\footnote{In practice, this set is reduced by taking into account that $(i', j')$ must be inside the board. To alleviate notations, we have not specified it in the formulation.}. Formally,

\begin{equation}
    \begin{aligned}
    \forall t \in [0, T-2], \; \forall (i, j) : \quad & x_{i,j,t} \implies \left( \bigvee_{(i', j') \in L(i,j)} x_{i',j',t+1} \right) \\
    \equiv \quad & \neg x_{i,j,t} \vee \left( \bigvee_{(i', j') \in L(i,j)} x_{i',j',t+1} \right)
    \end{aligned}
\end{equation}

We can additionally enforce the converse constraints. That is, if a cell $(i', j')$ is occupied at timestep $t+1$, the knight must have arrived from a valid preceding cell at timestep $t$. Let $L'(i', j')$ denote the set of legal origin cells that can reach $(i', j')$. Formally, 

\begin{equation}
    \begin{aligned}
    \forall t \in [0, T-2], \; \forall (i', j') : \quad & x_{i',j',t+1} \implies \left( \bigvee_{(i, j) \in L'(i',j')} x_{i,j,t} \right) \\
    \equiv \quad & \neg x_{i',j',t+1} \vee \left( \bigvee_{(i, j) \in L'(i',j')} x_{i,j,t} \right)
    \end{aligned}
\end{equation}

\paragraph{Results}
All the tests we have performed use the midrange CPU: Intel~(R) Core~(TM) i7--8565U 1.80GHz. The naive solution is able to solve $8 \times 8$ board in $\simeq 1.7$ [s]. It can also solve up to $13 \times 13$ boards in less than $10$ [s] but gets overwhelmed when reaching $15 \times 15$ boards, taking more than a minute to find the solution.

\section{Efficient solution}
\paragraph{Sequential encoding}
While the naive approach solves decently sized chessboards in reasonable time, it uses a quadratic number of clauses for encoding the ``exactly one'' constraints.
To reduce clause count and search space overhead, alternative encodings can be used. Among linear ``at-most-one'' encodings, the sequential counter encoding offers an good balance between simplicity and efficiency~\cite{holldobler2013efficient}.

The sequential counter introduces $n-1$ new auxiliary variables $a_k$ for a set of $n$ Boolean variables $x_0, \dots, x_{n-1}$. These auxiliary variables form a cumulative chain tracking whether any variable prior to index $k$ has been set to true. Once an indicator $x_k$ is true, the chain propagates this information forward to forbid any subsequent variable $x_m$ ($m > k$) from being true. In the following, we alleviate notations to abstract away board positions and timesteps, thus considering $x_k$ instead of $x_{i, j, t}$. The encoding is defined as:

\begin{align}
    \bigvee_{i=0}^{n-1} x_i && \text{At least one.} \\
    \neg x_k \lor a_k && \text{for } k \in [0, n-2] \\
    \neg a_{k-1} \lor a_k && \text{for } k \in [1, n-2] \\
    \neg x_k \lor \neg a_{k-1} && \text{for } k \in [1, n-1]
\end{align}

This encoding can be applied to both the single-cell and single-timestep constraints discussed in Section \ref{sec: naive_solution}. 

For example, applying it to the single-cell (per timestep) constraint would yield the following, conceptually. For a fixed timestep $t$, we flatten the board grid into a 1D sequence of length $n = M \times N$. Then, we introduce $n - 1$ auxiliary variables $a_{k, t}$ for this specific timestep $t$. Once a cell is occupied by the knight, the chain will forward this information and prevent the solver from putting the knight on any other cell on the board at time step $t$. The application to the single-timestep constraint follows the same principle.

\paragraph{Results}
However, as shown by Marques-Silva and Lynce~\cite{MarquesSilvaLynce07} (p. 11) on benchmark problems like the $N$-Queens problem, sequential counter encoding is not universally superior to pairwise encoding. While it reduces the theoretical clause complexity, it introduces significant runtime variance across problem instances. On smaller boards, sequential counter encoding often underperforms compared to the pairwise approach due to the overhead of auxiliary variables and slower unit propagation. Advanced variants of sequential encoding can mitigate these drawbacks, but since the naive pairwise formulation proved fast enough for our chessboard dimensions, we have not pursued further the sequential encoding variants.

\section{Counting}
\paragraph{Counting all solutions}
To count all solutions for a given board size, we enumerate the models found by the SAT solver across every possible starting cell $(i_0, j_0) \in [0, M-1] \times [0, N-1]$. Using the \texttt{PySAT} library, this is achived by calling the \texttt{enum\_models()} method after initializing the problem solver.

Solving a $3 \times 4$ chessboard requires approximately $1$ [s] and yields $16$ valid solutions, whereas a $5 \times 5$ board takes about $2\,s$ to find $1\,728$ solutions. These results match the exact solution counts reported in Wikipedia~\cite{wikipedia_knights_tour}.

\paragraph{Counting up to symmetry}
The easiest way to count solutions up to symmetry was to enumerate all the solutions, apply symmetries (rotation and mirroing) in order to check whether a solution is identical to another one. As with the previous counting method, this process evaluates every possible starting cell for a given board size. 

While this technique is not the most elegant nor computationally efficient approach, it remains fast enough for small grids, completing in just a few seconds for boards up to $5 \times 5$. Specifically, solving the $3 \times 4$ chessboard requires approximately $1.2$ [s] and yields $12$ unique solutions, whereas the $5 \times 5$ board takes $6.1$ [s] to identify $1,568$ unique solutions.

\section{Finding additional constraints}

We first enumerate every tour satisfying the base encoding, convert each one into a \textit{path}, that is, a sequence of positions indexed by time step $t$, and discard duplicates.

Among the resulting distinct paths, we pick one at random to serve as the reference path that will remain the unique solution.

We then examine the \textit{alternative paths} in arbitrary order. For each alternative still consistent with the clauses added so far, we locate the earliest time step $t \ge 1$ at which it diverges from the reference path, and force it with the unit clause $X_{i,j,t}$, where $(i,j)$ is the reference path's position at that step.

Because a clause is added only when the corresponding alternative would otherwise still be satisfiable, every added clause is necessary: removing any one of them immediately makes that alternative (and possibly others) satisfiable again.
